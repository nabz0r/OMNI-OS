# OMNI 0.3.0 — reviewed conversation import

Local evaluation delivery, 26 September 2026. macOS Apple Silicon and Android ARM64/x86_64 installers are available in `deliverables/OMNI-0.3.0-mvp/`, also provided as `deliverables/OMNI-0.3.0-mvp.zip`. The public 0.2.0 release is preserved. No 0.3.0 public release or store distribution is claimed.

## What changed

- Import supported ChatGPT, Claude or neutral JSON conversation exports through **Memory → Import text → Import chats**. Review one conversation and select the messages to keep. User messages are selected by default; AI replies are optional.
- Preview readable, role-labelled text before extraction. Extracted memories remain proposed, with no automatic confirmation or sharing grant. Closing the dialog clears the draft.
- Inspect decoded reviewed messages before extraction, including policy-sensitive text containing JSON-escaped newlines. Invalid declared envelopes fail before extraction.
- The separate browser extension adds selected-text support for the exact Z.AI chat origin and preserves short visible replies. It requires its documented loopback core; the standalone native apps do not automatically connect to it.
- Update the professional MVP roadmap, feature boundaries, build evidence and installation guides. The funding and assessment documents remain planning material; they do not establish customer traction or production readiness.

## Install or update

On an Apple Silicon Mac with macOS 14.4+, open the DMG, close an existing OMNI instance, and replace the application in Applications. This build is ad-hoc signed and not notarized. An existing vault may require owner authorization through macOS Keychain; do not delete the vault or its key.

On Android API 24+ with a current System WebView, install the APK. The package supports ARM64 and x86_64, with version name `0.3.0` and code `3000`. It uses the same development certificate as the previous local delivery. The tested 0.2.0 → 0.3.0 update preserved synthetic memory and settings without uninstalling. A physical phone was not tested. Never uninstall a personal vault to resolve a signature mismatch.

No Node.js, Rust, Docker or standalone OMNI server is needed to run either application. Models, API accounts and provider credits are not bundled. Each installation owns a separate encrypted vault.

## Remaining boundaries

Import uses explicit files and bounded supported schemas; it does not sign in to provider accounts, synchronize complete histories or deduplicate repeated imports. Images, attachments, tool output and hidden reasoning are excluded. Local extraction uses a bounded prefix; unavailable extraction falls back to a proposed excerpt. This release does not add universal HTTPS interception, cross-device synchronization, a recovery wizard, enterprise SSO, fleet policy administration or an independent security audit.
