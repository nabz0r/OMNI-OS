# OMNI 0.4.0 — Work with explicit authority

26 September 2026. Evaluation release with a dedicated Work screen shared by macOS and Android.

## What changed

- Dedicated single-owner work enrollment; named, expiring, revocable API clients; exact destination approvals and client-bound memory grants. The legacy integration credential is disabled in work mode.
- Explicit native loopback gateway activation, limited to approved-client Chat Completions and Messages routes. Owner administration remains on authenticated IPC.
- Opted-in scoped conversations with separate human/model roles, authorisation before bounded deterministic selection, request deduplication, uncertain-attempt acknowledgement, fixed retention, review and deletion.
- Passphrase-encrypted logical recovery with atomic restoration into an unused installation, a new device key, preserved destination identity and revoked recovered access.
- Managed-policy byte-digest pinning and unsafe-file rejection; local policy/preflight timing separated from provider latency.
- Two executable reference clients and a counted-provider controlled-context verification, plus expanded native acceptance and upgrade checks.

Read [Work](../WORK.md), [Recovery](../RECOVERY.md), [the supported matrix](../WORK_VERIFICATION.md) and [external review scope](../EXTERNAL_REVIEW.md) before using work information.

## Release evidence

Both installers use clean source checkpoint `699f95cc1d1eb458b245d76e8d297f98fa6e2c7c` on `main`. The controlled-loop baseline uses `c43a9e61de62f28a3a3b36c755ae0101b18f6ef0`; the core implementation is unchanged between those checkpoints. Core: 80 tests; controlled loop: 16 checks with zero denied provider arrivals. The exact installer hashes, native checks and observed baseline are recorded in [Validation](../VALIDATION.md) and the local delivery manifest. Build completion alone is not a runtime claim.

The preserved 0.3.0 and 0.2.0 records remain historical. No production signing, notarization, independent audit, shared tenant service, device-wide interception, physical-device matrix, commercial provider certification, automatic synchronization or SLA is established by this release.
