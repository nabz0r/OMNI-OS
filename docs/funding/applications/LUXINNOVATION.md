# Luxinnovation venture brief and Fit 4 Start preparation

Prepared 24 September 2026. Immediate route: an advisory discussion. Future application: Fit 4 Start #18, subject to call opening and its actual rules. Edition #17 is closed. This document is not an aid application or a request to be admitted late.

## Venture summary

OMNI is a local memory and request-control layer for AI tools. Its macOS and Android evaluation MVP lets users review memories, authorize context by destination and inspect disclosure receipts. It also checks supported requests and text attachments against local and provisioned policies. We propose to validate the product with small fintech engineering and operations teams in Luxembourg before developing a managed organisation offering.

## Digital track rationale

The project develops software for controlled AI use. Its main technical work is reliable local memory custody, explicit authorization and integration maintenance. Financial services is the proposed first market, not a claim that OMNI already performs regulated financial activity. Optional analytics use differential privacy; zero-knowledge proofs are not implemented.

## Customer need and proposed validation

The initial hypothesis is that professionals who use multiple assistants lose time rebuilding context and need clearer control of disclosures. We will compare OMNI with a manually prepared context brief on the same model and task budget. Interviews will test frequency, buyer ownership and willingness to pay before feature expansion. A commercial pilot will assess adoption, support effort and willingness to renew separately from the utility study.
